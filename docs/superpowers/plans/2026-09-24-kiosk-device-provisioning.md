# Kiosk Device Provisioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let SIMS staff add a new kiosk device (and recover a lost one) entirely from the SIMS web app — no Firebase Console visit, no copying an Auth UID by hand.

**Architecture:** A new staff-only Cloud Functions callable (`provisionKiosk`) uses the Admin Auth SDK (`ctx.auth`, already wired into every callable's context but currently unused) to create the kiosk's Firebase Auth email/password account AND its `kiosks/{uid}` allow-list document in one atomic-enough server-side call, then returns the generated email+password to the browser exactly once. A sibling callable (`resetKioskPassword`) regenerates the password for an existing device the same way. The SIMS "Guardians → Devices" tab's manual "paste a UID" form is replaced by a one-field "label only" form plus a one-time credential-reveal modal.

**Tech Stack:** Firebase Cloud Functions v2 (Node, `firebase-admin` Auth + Firestore Admin SDKs), React 19 SIMS admin app, Vitest (unit tests run via `vitest run src`, integration tests run via the Firebase emulator suite).

## Global Constraints

- Every new callable goes through the existing `staffCall` wrapper in `functions/index.js` (App Check enforced, staff-only) — the exact pattern `registerKioskFn`/`deactivateKioskFn` already use.
- Passwords must never be written to the audit log. `functions/src/audit.js` already states this rule in its own header comment; the `details` object passed to `audit()` for these two new actions must never include the password field.
- Kiosk email convention: `kiosk-<slug-of-label>@bnhs.local`, matching the existing hand-created accounts described in `DevicesTab.jsx`'s current comment (e.g. `kiosk-gate1@bnhs.local`).
- No Firestore rules changes are needed or in scope: Cloud Functions write `kiosks/{uid}` via the Admin SDK, which bypasses `firestore.rules` entirely, exactly like the existing `registerKiosk`/`deactivateKiosk` handlers already do.
- No changes are needed in the `bnhs-student-kiosk` repo. Its `/setup` page already accepts arbitrary email+password sign-in (`signInWithEmailAndPassword`) — it has no idea whether the account was hand-created in the Firebase Console or generated by `provisionKiosk`.
- The existing "paste an existing UID" registration form in `DevicesTab.jsx` is removed from the UI. The underlying `registerKiosk` / `registerKioskFn` function is **not** deleted — the table's existing "Re-activate" button already calls it with the device's own `k.id` (never asking the user for a UID), and must keep working unchanged.
- Credential reveal is a one-time on-screen modal with a "Copy" button per field. No QR code.
- A per-device "Reset password" action is required, using the same one-time reveal modal.

```js
import { randomBytes } from 'node:crypto';
import { FieldValue } from 'firebase-admin/firestore';
import { audit } from '../audit.js';
import { str } from '../lib/validators.js';

const EMAIL_DOMAIN = 'bnhs.local';
const MAX_EMAIL_ATTEMPTS = 5;

const slugify = (label) => label.trim().toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-+|-+$/g, '') || 'device';

// base64url avoids characters that need escaping when copy-pasted into a
// plain <input> or a terminal; 18 random bytes -> 24 chars, ~144 bits.
const generatePassword = () => randomBytes(18).toString('base64url');

export async function registerKiosk(ctx, data) {
  const { db, email } = ctx;
  const uid = str(data.uid, { name: 'uid', min: 4, max: 128 });
  const label = str(data.label, { name: 'label', min: 2, max: 40 });
  await db.doc(`kiosks/${uid}`).set({ label, active: true, createdBy: email, createdAt: FieldValue.serverTimestamp() }, { merge: true });
  await audit(db, { action: 'kiosk.registered', actorType: 'staff', actorUid: email, targetType: 'kiosk', targetId: uid, details: { label } });
  return { ok: true };
}

export async function deactivateKiosk(ctx, data) {
  const { db, email } = ctx;
  const uid = str(data.uid, { name: 'uid', min: 4, max: 128 });
  const reason = str(data.reason ?? '', { name: 'reason', max: 200 });
  await db.doc(`kiosks/${uid}`).set({ active: false, deactivatedAt: FieldValue.serverTimestamp(), deactivatedBy: email }, { merge: true });
  await audit(db, { action: 'kiosk.deactivated', actorType: 'staff', actorUid: email, targetType: 'kiosk', targetId: uid, details: { reason } });
  return { ok: true };
}

// Creates the device's own Firebase Auth account AND its kiosks/{uid}
// allow-list doc, so staff never has to visit the Firebase Console or
// handle a raw Auth UID. The generated email/password is returned to the
// caller exactly once -- nothing here persists the plaintext password.
export async function provisionKiosk(ctx, data) {
  const { db, auth, email: staffEmail } = ctx;
  const label = str(data.label, { name: 'label', min: 2, max: 40 });
  const base = slugify(label);
  const password = generatePassword();

  let userRecord;
  for (let attempt = 0; ; attempt += 1) {
    const candidateEmail = attempt === 0 ? `kiosk-${base}@${EMAIL_DOMAIN}` : `kiosk-${base}-${attempt + 1}@${EMAIL_DOMAIN}`;
    try {
      userRecord = await auth.createUser({ email: candidateEmail, password });
      break;
    } catch (e) {
      if (e.code === 'auth/email-already-exists' && attempt < MAX_EMAIL_ATTEMPTS - 1) continue;
      throw e;
    }
  }

  await db.doc(`kiosks/${userRecord.uid}`).set({ label, active: true, createdBy: staffEmail, createdAt: FieldValue.serverTimestamp() }, { merge: true });
  await audit(db, { action: 'kiosk.provisioned', actorType: 'staff', actorUid: staffEmail, targetType: 'kiosk', targetId: userRecord.uid, details: { label, email: userRecord.email } });
  return { uid: userRecord.uid, email: userRecord.email, password };
}

// Regenerates the password for an already-registered device (lost sticky
// note, suspected compromise). The uid and kiosks/{uid} doc are unchanged --
// only the Auth credential moves.
export async function resetKioskPassword(ctx, data) {
  const { db, auth, email: staffEmail } = ctx;
  const uid = str(data.uid, { name: 'uid', min: 4, max: 128 });
  const password = generatePassword();
  const userRecord = await auth.updateUser(uid, { password });
  await audit(db, { action: 'kiosk.password_reset', actorType: 'staff', actorUid: staffEmail, targetType: 'kiosk', targetId: uid });
  return { uid, email: userRecord.email, password };
}
```

```jsx
import { useState } from 'react';
import { useCollection } from '../../hooks/useCollection.js';
import { call } from '../../data/guardians.js';
import { T, S } from '../../styles.js';
import { Btn, Inp, Field, Card, Confirm, Modal } from '../../components/ui.jsx';

const copyToClipboard = async (text) => {
  try { await navigator.clipboard.writeText(text); }
  catch { /* clipboard unavailable (e.g. insecure context) -- the value is still visible to select and copy by hand */ }
};

// Kiosk accounts are created here, not by hand in Firebase Auth: provisionKiosk
// (functions/src/handlers/kiosks.js) creates the Auth user AND the kiosks/{uid}
// allow-list doc in one call, so staff never needs a Firebase Auth UID.
export default function DevicesTab() {
  const kiosks = useCollection('kiosks');
  const [label, setLabel] = useState('');
  const [busy, setBusy] = useState(false);
  const [err, setErr] = useState('');
  const [confirm, setConfirm] = useState(null);
  const [credentials, setCredentials] = useState(null); // { label, email, password } | null

  const create = async () => {
    setBusy(true); setErr('');
    try {
      const { email, password } = await call.provisionKiosk({ label: label.trim() });
      setCredentials({ label: label.trim(), email, password });
      setLabel('');
    } catch (e) { setErr(e.message || 'Could not create the device.'); }
    setBusy(false);
  };
  const resetPassword = async (k) => {
    setErr('');
    try {
      const { email, password } = await call.resetKioskPassword({ uid: k.id });
      setCredentials({ label: k.label, email, password });
    } catch (e) { setErr(e.message || 'Could not reset the password.'); }
  };
  const deactivate = async (k) => { await call.deactivateKiosk({ uid: k.id, reason: 'Deactivated from SIMS' }); setConfirm(null); };

  return (
    <>
      <Card style={{ padding: 20, marginBottom: 16 }}>
        <h2 style={S.h2}>Add a new kiosk device</h2>
        <p style={{ fontFamily: T.body, fontSize: 13, color: T.inkMuted }}>Name the gate. SIMS creates the device's sign-in and shows it to you once — copy it into that computer's <code>/setup</code> page.</p>
        {err && <div style={{ color: T.absent, fontSize: 12, marginBottom: 8 }}>{err}</div>}
        <div style={{ display: 'grid', gridTemplateColumns: '1fr auto', gap: 12, alignItems: 'end' }}>
          <Field label="Gate label (shown to parents)"><Inp value={label} onChange={(e) => setLabel(e.target.value)} placeholder="Main Gate" /></Field>
          <Btn onClick={create} disabled={busy || !label.trim()} style={{ marginBottom: 14 }}>{busy ? 'Creating…' : 'Create device'}</Btn>
        </div>
      </Card>
      <Card>
        <table style={{ width: '100%', borderCollapse: 'collapse', fontFamily: T.body, fontSize: 13 }}>
          <thead style={S.thead}><tr><th style={S.th}>Label</th><th style={S.th}>Status</th><th style={S.th}>Last seen</th><th style={S.th}></th></tr></thead>
          <tbody>
            {kiosks.map((k) => (
              <tr key={k.id}>
                <td style={S.td}>{k.label}</td>
                <td style={S.td}>{k.active ? 'Active' : 'Deactivated'}</td>
                <td style={S.td}>{k.lastSeenAt?.toDate ? k.lastSeenAt.toDate().toLocaleString() : '—'}</td>
                <td style={{ ...S.td, display: 'flex', gap: 8, justifyContent: 'flex-end' }}>
                  {k.active
                    ? <>
                        <Btn variant="ghost" onClick={() => resetPassword(k)}>Reset password</Btn>
                        <Btn variant="ghost" onClick={() => setConfirm(k)}>Deactivate</Btn>
                      </>
                    : <Btn variant="ghost" onClick={() => call.registerKiosk({ uid: k.id, label: k.label })}>Re-activate</Btn>}
                </td>
              </tr>
            ))}
          </tbody>
        </table>
      </Card>
      {confirm && <Confirm message={`Deactivate "${confirm.label}"? The kiosk stops scanning within seconds.`} label="Deactivate" onYes={() => deactivate(confirm)} onNo={() => setConfirm(null)} />}
      {credentials && (
        <Modal onClose={() => setCredentials(null)}>
          <h2 style={S.h2}>{credentials.label} is ready</h2>
          <p style={{ fontFamily: T.body, fontSize: 13, color: T.inkMuted }}>Copy these into that computer's <code>/setup</code> page now — the password won't be shown again.</p>
          <Field label="Device email">
            <div style={{ display: 'flex', gap: 8 }}>
              <Inp readOnly value={credentials.email} onFocus={(e) => e.target.select()} />
              <Btn variant="ghost" onClick={() => copyToClipboard(credentials.email)}>Copy</Btn>
            </div>
          </Field>
          <Field label="Password">
            <div style={{ display: 'flex', gap: 8 }}>
              <Inp readOnly value={credentials.password} onFocus={(e) => e.target.select()} style={{ ...T.num }} />
              <Btn variant="ghost" onClick={() => copyToClipboard(credentials.password)}>Copy</Btn>
            </div>
          </Field>
          <div style={{ display: 'flex', justifyContent: 'flex-end', marginTop: 16 }}>
            <Btn onClick={() => setCredentials(null)}>Done</Btn>
          </div>
        </Modal>
      )}
    </>
  );
}
```
